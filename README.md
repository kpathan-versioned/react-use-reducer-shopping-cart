# React Shopping Cart with useReducer

A React Shopping Cart component built to practise complex state management using React's `useReducer` hook.

## Features

- Add products to the cart
- Increment and decrement product quantities
- Automatically remove products when quantity reaches zero
- Remove individual products
- Apply and remove a 10% discount coupon
- Calculate subtotal, discount, and final total dynamically
- Clear the entire cart

## Tech Stack

- React.js
- JavaScript (ES6+)
- React Hooks: `useReducer`
- Array methods: `find()`, `map()`, `filter()`, and `reduce()`

## Key Learnings

- Managing multiple related state transitions with a reducer
- Using `dispatch()` to trigger actions
- Implementing immutable state updates
- Calculating derived values from state
- Handling conditional rendering in React

## Getting Started

This repository currently contains the Shopping Cart component source code. To run it, place the component inside a React application and render it from your app entry point. Ensure the component's dependencies and imports are configured.
